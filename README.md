## 📖 About the project

This **simple Todo App** project uses a simple interface with basic **HTML** and **CSS**. Its main purpose is to teach how to work with the **DOM** and **Local Storage**, how to manage the task array, and how to check if a task is complete or not. It is very useful for beginners to apply what they have learned
in the fundamentals of **JavaScript**.

## ✨ Features

- Saving tasks to `Local Storage`.
- Check if there are any tasks in `Local Storage`.
- Check if the user has typed anything in the `input field`.
- Using `DOM` to generate a task with buttons action.
- Capture the task via `ID`.
- `button actions` first one for `done` task and the other one for `delete` the task from `Local storage` and from the `U|I` Page

## 🛠️ Technologies Used

- **HTML** : Page structure.
- **CSS** : Styling.
- **JavaScript (ES6)** : Programming logic, interaction, and saving in Local Storage.

## 💻 How to run it locally (on your device)

- Download the project as a ZIP file or use the command :

```bash
  git clone https://github.com/Fadi-Yaj/Todo-App.git
```

## 🖱️ Usage

- Write your task in the `input field`, and when you have finished the task, press the `Done` button.
- If you no longer want the task you wrote previously or you need to `delete` a task, simply press the `delete` button.

## 🚀 Future developments (Planned features)

- Displaying task statistics (total tasks vs. completed tasks).
- Editing existing task text.
- Adding a Dark Mode (night mode).
- Integrating the Eisenhower Matrix for better time management.
- Implementing (drag-and-drop) functionality to move tasks between different lists.
